# Cycle Count Inventory Controls
Segment inventory by value/risk and set count frequency. Compare physical count to system quantity, investigate variances before posting, record reason codes, and trend accuracy. Review receiving, picking, production issue/return, scrap, and location controls that cause repeated differences.
