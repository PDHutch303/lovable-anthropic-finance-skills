# Acquisition Synergy Tracking
Start with the approved deal-case synergy list. For each item track baseline, owner, action, timing, one-time cost, run-rate benefit, realized P&L/cash benefit, and confidence. Avoid double-counting benefits already embedded in organic forecast changes.
