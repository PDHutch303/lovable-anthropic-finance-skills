# Tax Return Review
Tie return amounts to final books, prior returns, K-1s, payroll, fixed assets, debt, estimated payments, and supporting schedules. Review entity information, ownership, elections, carryforwards, basis-sensitive items, state filings, book-tax differences, related parties, and large year-over-year changes.

## Output
Provide tie-out status, questions, discrepancies, missing forms/support, and items for preparer review.

## Guardrails
Do not sign off on a tax position solely because software accepted it.
