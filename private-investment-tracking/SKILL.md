# Private Investment Tracking
Maintain a complete roll-forward for illiquid investments.

Track opening basis/cost, contributions, capital calls, distributions, realized gains/losses, income, fees, valuation changes, ending carrying value, ownership, commitments, unfunded commitments, K-1 status, and supporting documents. Distinguish accounting carrying value, tax basis, and management-estimated fair value when they differ.

## Output
Produce an investment ledger, commitment schedule, cash-flow history, return metrics when data supports them, K-1 tracker, and exception list.

## Guardrails
Never substitute estimated value for audited or sponsor-reported value without labeling it.
