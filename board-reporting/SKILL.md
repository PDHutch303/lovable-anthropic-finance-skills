# Board Reporting

Build a decision-oriented finance package rather than a data dump. Summarize revenue, gross margin, EBITDA/operating income, cash, debt, working capital, capex, and other business-specific KPIs. Compare actuals to budget, forecast, prior period, and prior year where relevant. Explain material variances using quantified drivers. Highlight liquidity, covenant, concentration, operational, and forecast risks. Separate facts, management estimates, and recommendations. Output an executive summary, KPI table, key financial statements, variance commentary, cash/debt outlook, risks, and decisions requested from the board or leadership team.
