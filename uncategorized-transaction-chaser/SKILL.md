# Uncategorized Transaction Chaser
Group open transactions by vendor, amount, date, account, and likely business purpose. Apply existing approved coding rules first; do not ask questions already answerable from source records. For unresolved items, draft a compact client inquiry showing transaction date, payee, amount, current account, and 2–4 plausible categories plus “other.” Prioritize by materiality, age, close impact, tax sensitivity, and recurrence. Track response status and convert answers into proposed coding rules only after approval. Never auto-code an ambiguous owner, related-party, loan, capital, or tax transaction.
