# Post-Close Finance Integration
Establish opening balances and close ownership; secure banking/payment access; map COA; reconcile payroll/AP/AR/inventory/fixed assets; define intercompany and management fees; align close calendar and policies; preserve historical data; establish reporting/KPIs; and create an integration issue log with owners/deadlines.
