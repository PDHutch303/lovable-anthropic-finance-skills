# Valuation
Estimate enterprise and equity value using multiple methods and reconcile the results.

## Workflow
1. Normalize historical earnings and identify non-recurring items.
2. Select appropriate methods: DCF, trading multiples, transaction multiples, or asset approach.
3. Define revenue, margin, capex, working-capital, tax, discount-rate, and terminal assumptions.
4. Build a valuation range rather than a single point estimate.
5. Reconcile enterprise value to equity value using debt, cash, and debt-like items.
6. Run sensitivity analysis on the most important assumptions.

## Output
Show methods, assumptions, valuation ranges, bridge from enterprise to equity value, sensitivities, and key diligence risks.

## Guardrails
Clearly distinguish indicative analysis from a formal appraisal or fairness opinion.
