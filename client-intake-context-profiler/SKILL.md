# Client Intake Context Profiler
Create a profile containing entities, ownership, tax classification, accounting basis, COA conventions, materiality, recurring vendors/customers, approved coding rules, intercompany relationships, bank/processor mappings, close calendar, reporting package, tax jurisdictions, reviewer thresholds, unusual-accounting policies, and open issues. Separate permanent rules from period-specific facts. Date every rule and identify its approver/source. Do not propagate one entity’s rule to another without evidence. Use the profile to reduce repetitive questions while still surfacing exceptions that fall outside approved patterns.
