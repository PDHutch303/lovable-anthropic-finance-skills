# Sources & Uses
List uses: purchase consideration, debt payoff, fees/expenses, financing fees, working-capital funding, cash to balance sheet, and other closing uses. List sources: buyer equity, debt tranches, seller note, rollover equity, target cash if permitted, and other financing. Ensure sources equal uses and tie to closing documents.
