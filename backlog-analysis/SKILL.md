# Backlog Analysis
Track signed contract/order value not yet recognized, expected start/finish, revenue conversion by month, estimated margin, customer, branch, and service line. Separate awarded-not-signed pipeline from contractual backlog. Compare backlog with labor/capacity and identify concentration/cancellation risks.
