# Substantive Testing
Define population, assertion, test objective, procedure, sample or selection method, source evidence, exception criteria, and conclusion. Common procedures include vouching recorded items to support, tracing source records to the ledger, recalculation, external evidence, cutoff testing, and subsequent-disbursement/receipt review.

## Output
Provide test sheet, selections, evidence, exceptions, conclusion, and follow-up actions.
