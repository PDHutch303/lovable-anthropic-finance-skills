# Industry Playbook Index

The root `accounting-cfo` skill should combine the user's requested accounting workflow with the relevant industry layer.

## Family office / private equity / trusts & estates
Use for family-office investment entities, direct investments, LP/fund positions, trusts, estates, and portfolio-company oversight.

Key playbooks: `family-office-pe-investment-accounting`, `fund-investment-rollforward`, `capital-account-tracking`, `partnership-waterfalls`, `preferred-return-waterfalls`, `carried-interest-analysis`, `investment-basis-tracking`, `k1-investment-reconciliation`, `unfunded-commitment-tracking`, `investment-performance-irr-moic`, `portfolio-company-reporting`, `family-office-consolidation`, `family-office-cash-forecasting`, `trust-accounting`, `trust-distribution-tracking`, `estate-administration-accounting`, `beneficiary-reporting`, and `gift-estate-tax-readiness`.

## Manufacturing
Use for manufacturers with raw material, WIP, finished goods, BOMs, work orders, standard cost, machine/labor routing, and production variances.

Key playbooks: `manufacturing-cost-accounting`, `standard-costing`, `actual-vs-standard-cost`, `purchase-price-variance`, `material-usage-variance`, `labor-efficiency-variance`, `overhead-absorption`, `bom-costing`, `work-order-costing`, `wip-reconciliation`, `finished-goods-reconciliation`, `inventory-reserve-obsolescence`, `scrap-yield-analysis`, `capacity-utilization`, `machine-hour-costing`, `make-vs-buy`, `product-sku-profitability`, `landed-cost`, and `cycle-count-inventory-controls`.

## Blue-collar service / construction
Use for HVAC, plumbing, electrical, roofing, landscaping, construction, and field-service businesses.

Key playbooks: `job-profitability`, `service-line-profitability`, `technician-profitability`, `labor-utilization`, `labor-burden`, `construction-job-costing`, `construction-wip-accounting`, `contract-assets-liabilities`, `backlog-analysis`, `service-agreement-recurring-revenue`, `fleet-truck-costing`, `truck-stock-inventory`, `dispatch-kpi-analysis`, `callback-warranty-costing`, `customer-acquisition-payback`, `branch-location-profitability`, `overtime-analysis`, `field-service-cash-conversion`, and `13-week-cash-flow-service-company`.

## Plastic surgery / medical / aesthetic practice
Use for self-pay medical, plastic surgery, medspa/aesthetic, and mixed-payor practices.

Key playbooks: `medical-practice-accounting`, `procedure-profitability`, `provider-productivity`, `provider-compensation`, `patient-deposit-deferred-revenue`, `merchant-financing-reconciliation-medical`, `refund-credit-balance-review`, `medical-supply-implant-inventory`, `operating-room-profitability`, `medical-marketing-roi`, `payor-selfpay-mix-analysis`, and `practice-cash-flow-forecast`.

## Acquisitions / portfolio-company integration
Use during diligence, closing, opening-balance-sheet work, post-close integration, and portfolio-company ownership.

Key playbooks: `purchase-price-allocation`, `opening-balance-sheet`, `working-capital-true-up`, `seller-note-accounting`, `earnout-accounting`, `transaction-cost-accounting`, `goodwill-intangibles`, `post-close-integration`, `100-day-finance-plan`, `acquisition-synergy-tracking`, `sources-and-uses`, and `rollover-equity`.

## Routing examples
- Manufacturing monthly close = `close-management` + `manufacturing-cost-accounting` + `wip-reconciliation` + `inventory-reserve-obsolescence` + `variance-analysis`.
- Family-office quarterly reporting = `family-office-consolidation` + `fund-investment-rollforward` + `investment-performance-irr-moic` + `unfunded-commitment-tracking` + `family-office-cash-forecasting`.
- Field-service monthly CFO review = `controller-review` + `job-profitability` + `labor-utilization` + `service-agreement-recurring-revenue` + `field-service-cash-conversion`.
- Plastic-surgery practice review = `medical-practice-accounting` + `procedure-profitability` + `provider-productivity` + `patient-deposit-deferred-revenue` + `medical-marketing-roi`.
- New acquisition = `sources-and-uses` + `opening-balance-sheet` + `working-capital-true-up` + `purchase-price-allocation` + `100-day-finance-plan`.
