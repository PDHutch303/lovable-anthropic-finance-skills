# Portfolio Allocation Drift
Map holdings to the approved asset-class taxonomy, including look-through only when reliable data exists. Calculate current weight, target weight/range, absolute drift, and concentration by issuer, asset class, geography, liquidity, and account/entity. Identify positions outside policy ranges and estimate the trades or cash flows that would mathematically restore targets, but present them as scenario analysis rather than personalized trade recommendations. Consider taxes, liquidity constraints, lockups, restricted assets, and private-investment commitments before any rebalancing analysis. Use only the approved IPS/targets supplied by the user or adviser.
