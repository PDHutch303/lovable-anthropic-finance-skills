# Usage Billing Review
Reconcile source usage to billed quantity and rate. Check customer, period, unit definition, tier thresholds, minimum commitments, overages, credits, proration, free allowances, taxes, and contract amendments. Recalculate expected charges independently and compare to the draft/exported invoice. Isolate data gaps, duplicate events, late events, negative usage, tier-boundary errors, and unbilled usage. Report expected billing, actual billing, variance, cause, and required correction. Preserve raw usage evidence and never modify source logs to force a match.
